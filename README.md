# Hopin — Patio Cafe

Interactive web experience for **Hopin — Patio Cafe** (`17/2, New Palasia, Indore, Madhya Pradesh 452001`), featuring a 3D architectural entry portal, rotating 12-Gate culinary ring across 83 vegetarian dishes (with Jain options), 3D hallway gallery, heritage bungalow showcase, live Google Maps & Places integration, and a post-order Kitchen Ticket with Hopin Patio Postcard review flow.

## Getting Started

```bash
npm install
cp .env.example .env
# Optional: add your Google Maps Platform browser key to VITE_GOOGLE_MAPS_API_KEY in .env
npm run dev
```

## Scripts

- `npm run dev` — Start the local Vite development server on port 3000
- `npm run build` — Build the production bundle
- `npm run lint` — Run TypeScript type checking (`tsc --noEmit`)
